# LOKI Final State (north star, Phase 0)

One coherent magician: observation → intuition → interaction → uncertainty →
subtle acquisition → adaptation → dramatic reveal.

- **Card flagship** passes the north-star test: after the reveal the participant
  wonders HOW, not which questions were asked.
- **Boundaries hold:** inference = belief, Brain = strategy, performance = wording,
  stage = experience. No learned component rewrites the posterior.
- **One learned thing earns its place:** policy (then participant model, then dialogue),
  each beating its baseline on accuracy + magic-factor delta or it doesn't ship.
- **Player/Research/Debug modes** separated; raw media stays in-browser; archive stays
  consent-gated.
- **Evidence:** simulation deltas + human trials (A/B/C) + failure analysis, not vibes.
